# Review of docs/plans/accounts-and-developer-api.md

Verdict: ready after fixes. The direction is sound and the auth library does offer the options the plan leans on, but the guard of step 1 as written breaks every sign-in callback and the dev and test setup, the claim step as written lets one organisation read another's files, and several controls (suspension, verify-first, price scopes) can be walked around through routes the plan does not mention.

Labels: [V] opened at source today (25 Nov 2026), [S] search summary only, [E] my estimate. "ab:" is `/home/claude/ref/assistant-build`. "lib:" is the published package `better-auth@1.7.27` (the pinned version, `ab:apps/server/package.json:28`), downloaded from the npm registry today and read on disk. Plan line numbers are those of the plan file.
