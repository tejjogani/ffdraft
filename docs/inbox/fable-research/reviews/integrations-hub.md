## Suspicions, not verified

- **The Edge EULA and file imports.** I could not settle whether a file that a jeweler imports through The Edge's own wizard is "integrating or interfacing other software". The wizard is Edge's feature; the clause is broad. This is for counsel (finding 1).
- **Tally `Alter` with a partial master.** It may clear fields the XML leaves out (opening balance, tax details). Not checked at source. If true, "alter" is a books risk and step 4 should create only, never alter, unless the item was created by Pavé.
- **Tally name matching.** Working knowledge says Tally ignores case and spacing when it matches master names. If so, two SKUs that differ only by a space or case collide and one overwrites the other. Not checked.
- **Whether Tally's HTTP server listens on every network interface.** The help pages only show `localhost:9000`. Not stated at source.
- **Whether the port works in Tally's trial or unlicensed mode.** The cost page offers a 7-day trial [V]; no page I opened says what it allows.
- **Which Shopify role or plan can create a Dev Dashboard app for its own store,** and whether every ordinary merchant store sits in an organisation that can own an app. The pages opened do not say. If not, the "merchant's own app" route fails for small shops.
- **A free public Shopify app that bills outside Shopify.** The partner agreement's billing clause was read only through a summary of the first 100,000 characters; whether it covers a subscription to a separate product is unknown.
- **Whether one Shopify store can sell quantity 1 twice** in simultaneous checkouts. The plan and R21 both say unverified; I did not get further.
- **Walking zod `.meta({ restricted: true })` through unions, arrays and records at run time.** Likely workable in zod 4; not spiked. Another reason to fail closed (finding 3).
- **An `.xlsx` reader's safety.** Common npm packages for this have had parsing vulnerabilities; none was checked because the plan names none.
- **Tally under emulation on the founder's Mac.** Unknown; affects finding 11.
- **`stones.csv` carries `sourcing_sku` and `sourcing_url`** from the partner marketplace. If stone lines go to Shopify metaobjects as they are, a public listing could expose supplier links.
