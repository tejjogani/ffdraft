# Review of docs/plans/pave-file-format.md
Verdict: ready after fixes (the envelope and the order of checks are sound, but as written version 2 saves files that cannot rebuild some pieces, Share copies that either fail to open or leak what the sheet promises to keep, and the "pricing model stays whole" claim is not true of the code as it stands).

Paths below are in `/home/claude/ref/assistant-build` unless they start with `docs/plans` or `docs/research` (those are in `/home/claude/pave-research`). Nothing was run: the reference tree has no `node_modules`. Every code claim is from reading the file and line given.

## Suspicions, not verified

If that is right, a web page that rebinds its name to 127.0.0.1 could call `pieces.saveFile { profile: 'working' }` and fetch the asset: one call for a piece with everything in it. The RPC route does require a JSON content type, which stops plain cross-site forms. I did not test it. It predates this plan, but the Working copy raises the stakes.
- **three.js fetching outside addresses from a GLB** (finding 9) is from memory of the loader's source, not from a page opened today.
- **`.pave` as an extension or a mark** (finding 15c): not checked by anyone, for the reason given.
