# Ten jobs to try at the jeweler’s bench

Use **Projects** to open a project. Its **CAD**, **Renders**, **Sourcing** and **On model** screens all work on the piece named in the header. For the HBR bracelet or another original, use the project’s **••• → Duplicate** and work on the copy. A fresh solitaire and an eternity ring from the template picker cover the stone-fitting tests. No terminal commands are needed in a running studio.

For each job, record **worked**, **needed help**, or **blocked**, plus the first confusing click. When reviewing an image, circle the area you would ask a retoucher to change. Keep the original CAD or reference render alongside Pavé if you have it.

| # | Try this | What to look for | Your result |
|---|---|---|---|
| 1 | Import a familiar jewelry **.3dm** into an empty project's **CAD → Import model**. Enable **Include editable curves**. Select a stone, isolate it, then exit isolation. | The stone, adjacent metal, scale and orientation agree with the original. Expand **Construction curves** when you need the guides. Record any skipped geometry reported by the importer. | |
| 2 | Download the [shank practice file](../apps/studio/public/examples/shank-guides.3dm) and import its editable curves into a fresh project. Under **Add feature → Sweep 2 rails**, choose **Inner rail**, **Outer rail**, then **Band section**. Choose **Solid → Create feature**. | A continuous band with an 18 mm bore, 22 mm outer diameter and 3 mm height. Reopen the project, edit a source curve, Undo, and use **Export → STEP** to check it in your usual viewer. | |
| 3 | In an eternity template, select one stone in the row. In its Inspector, under **Stone displacement**, enter X **0.2 mm** and choose **Apply displacement**. Reload and choose **Reset position**. | Only the selected stone moves. Look at its seat and its neighbors before resetting it. The shared setting stays in its generated position. | |
| 4 | In a solitaire, select the band and change its width by a known amount. Change its alloy to rose gold in **Material** and inspect the result in **Rendered** view. Select the head and try another setting style. | You can tell which part each edit affects. Inspect the claw tips and gallery from below. Undo the last edit and check which change remains. | |
| 5 | In the HBR copy, open **Sourcing**, select a diamond under **Stone in CAD** and choose **Search inventory**. Choose a color grade and search again. | Compare the three CAD dimensions with the listings. Only diamonds appear in the imported diamond picker. Opening a listing leaves the CAD as drawn. | |
| 6 | In the solitaire's **Sourcing** screen, choose **Find diamonds**, preview two listings, then **Fit this stone** on the one you prefer. Return to CAD and use Undo. | Compare the listed length, width and depth, the seat preview and the fitted SKU. Undo restores the original. Imported stones have a separate **Set up this stone for a CAD replacement** action. | |
| 7 | In the HBR copy, open **Renders → Add view → Copy current**. Name one view **Straight** and the copy **Bracelet**. In the copy choose **Ring pose → Circular band**, then frame the piece with **Expand preview**. | Switching between the shots restores their respective pose and camera. Check CAD to confirm the modeled bracelet is still straight. A pose needs separate links or settings. | |
| 8 | Copy a render view and keep its camera fixed. Under **Light → Studio lights**, adjust one strip light. Render the original and the copy. | Compare the actual Blender takes. Look at the inside of the band, claw tips and diamond facets. Note clipped highlights, flat metal, missing colors or framing you would change before publishing. | |
| 9 | In **Renders**, prepare a still with **Backdrop → Transparent** and **Ground → None**. Open **On model**, choose the current take, and place the piece on your own hand or wrist photo. Adjust size and rotation, then choose **Download PNG**. Your personal photo stays in the browser. | Inspect the downloaded file at full size. This manual layout uses the rendered jewelry pixels. Choose a pose where the jewelry’s visible edges suit the photo. | |
| 10 | For an AI shoot, make a finished still of the current CAD, then open **On model**. Create a fictional adult model, choose **Approve for shoots → Use model**, pick a placement and describe the shot. Choose **Estimate image** and review it before **Generate image**. | Requires a connected reference-capable image provider in **Settings → AI**. Compare the returned concept against the source still for stone count, mount, alloy and scale. Record any change in the jewelry. Download the preview for review. | |

If you use project Claude, try the same instruction on a selected stone, such as “Show me live Diaex candidates for this diamond and preview the second candidate’s fit.” A Claude credential is required for live chat. Compare the SKU, dimensions and current project with the manual preview.

**Feedback to send** — job number, project, expected result, what happened, and a screenshot or the saved image. For a render include the view name. For a sourcing issue include the public stone ID. For a CAD issue include the selected part name and the units you entered.
