# Editing a handmade mounting

A jeweler can select existing mount members, edit them together at measured positions, and link them to the dimensions of one confirmed stone. Keep each original body, its ID, material, source geometry and placement. Save edits in the project graph so that manual work and measured supplier changes can be undone.

1. Exercise the kernel on neighboring claws, a rail and an untouched neighbor. Verify affine control edits against native solids and continuous deformation against the original mesh connectivity.
2. Add a versioned selection inspection and an atomic edit command. Check selected bounds, material assignment, source identities and fit dependencies. Replaying a fit always starts from original dimensions.
3. Place the same eight control points in the Studio editor, with numerical entry, draggable handles, preview, editing of individual parts, and a choice of deformation modes.
4. Exercise Studio, Python and the project assistant API. Inspect a returned Rhino file, the casting output, and a saved and reopened Pavé file.
