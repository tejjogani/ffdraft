# Section modeling and the first render

A designer can draw measured cross sections, make a loft or sweep, edit a source, and see the new geometry in the same project. Claude and Python use the same versioned edits. A finished solid can go straight to Blender.

1. Register ordered curve dependencies and explicit sheet or solid output. Verify rebuilds, diagnostics, surface area, casting volume and exact STEP export.
2. Use the same ordered input picker for creating and editing a loft, a one-rail sweep or a two-rail sweep. Give parallel sketches an editable plane position.
3. Exercise the stored graph from Studio, Python and the project assistant. Reopen after a source edit and confirm the selected project and measured result.
4. Start managed Blender setup when a local designer requests a final render. Show progress, resume the requested shot and preserve an explicit browser preview. Check installation, failure, cancellation, concurrent requests and the finished image.
